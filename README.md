# 나를 찾는 여정 (Self Journey)

동양의 사주와 서양의 별자리, 이름의 오행과 무의식의 도형, 나의 색과 92문항의 성향까지 —
**여섯 개의 거울로 나를 여섯 갈래(命·緣·運·像·格·跡)로 비추는** 자아 발견 웹 프로그램입니다.

🔗 **바로 써보기**: https://selflog.netlify.app

## 특징

- **설치·서버 없음** — 순수 정적 웹(HTML/CSS/JS). 링크만 있으면 어디서든 실행.
- **개인정보 무전송** — 생년월일·검사 답 등 모든 계산이 **당신의 브라우저 안에서만** 이뤄지며 서버로 전송되지 않습니다.
- **박사급 만세력** — 한국천문연구원(KASI) 기준 음양력 + 24절기 정밀 시각 + 진태양시(경도·균시차·역사적 표준시) 보정으로 사주팔자를 분 단위까지 정확하게 계산.

## 담긴 것

| 갈래 | 내용 |
|---|---|
| 命 | 사주명리 · 성명학 · 별자리 · 수비학 · 탄생석 |
| 緣 | 궁합 · 연애 추천 · 배우자/부모/자녀운 |
| 運 | 올해 운세 · 열두 달 흐름 |
| 像 | 도형심리 · 퍼스널컬러 |
| 格 | 92문항 성향검사(자체 문항) |
| 跡 | 나의 이야기(자서전) |

## 구성

```
index.html      메인 화면
js/             엔진
 ├ manseryeok.js      만세력(사주팔자)
 ├ naming.js          성명학(소리오행·81수리)
 ├ questions.js       92문항
 ├ assessment.js      성향 채점
 ├ personal_color.js  퍼스널 컬러
 ├ zodiac_west.js     서양 별자리
 ├ numerology.js      수비학·타로·탄생석
 ├ fortune.js         운세·인연·궁합
 ├ report_content.js  리포트 해설
 ├ app.js             화면 흐름
 └ (lunar_table / solar_terms / hanja_db).js   데이터
```

## 로컬 실행

`index.html`을 브라우저로 열기만 하면 됩니다. (별도 빌드·설치 불필요)
